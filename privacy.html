Privacy Policy

Aztec Stream Tools is a desktop app the channel owner runs on their own PC. Last updated: November 6, 2026.

What it accesses

When the owner signs in with Google, the app uses the YouTube permission (youtube.force-ssl) to manage that owner's own live streams and to read and post live chat messages on their own channel.

Where the data stays

The sign-in tokens and chat data are stored only on the owner's own PC. They are not sent to the app's developer, and there is no server run for this app.

Sharing

Google user data is not sold, and it is not shared with advertisers or data brokers. The app may send chat text to AI services the owner has set up, to help write replies. Its use of Google data follows the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time at Google Account permissions. Deleting the app's data folder removes the local copies.
